# 命令デコードの実装 (Chisel 編)
前回は命令フェッチを行う回路を実装したので、今回はフェッチした命令を解読する命令デコード (Instruction Decode: ID) の実装を行います。
具体的には、各命令で共通のレジスタ番号 ```rs1```、```rs2```、```rd``` の値を取得して、指定されたレジスタから値を読み出す機能を実装します。

## パッケージ名の変更
前回、命令フェッチの実装に合わせてパッケージ名を ```fetch``` としていましたが、これからほかのステージも実装していくことになるので、```rv32cpu``` にパッケージ名を変更しておきます。

## Chisel の実装
RISC-V では命令の種類によらず、レジスタアドレスの位置は共通化されています。
具体的には各命令の次のビット位置に格納されています。

- ```rs1```: 15bit 目から 19bit 目
- ```rs2```: 20bit 目から 24bit 目
- ```rd```: 7bit 目から 11bit 目

そのため、レジスタアドレスの取得は以下の通り実装できます。

```Core.scala```
```scala
val rs1_addr = inst(19, 15)
val rs2_addr = inst(24, 20)
val wb_addr  = inst(11, 7)
```

ただし、RISC-V では 0 番目のレジスタが必ず 0 であることが規定されています。
そのため、以下のようなマルチプレクサを通して値を取得する必要があります。

```scala
val rs1_data = Mux((rs1_addr =/= 0.U(WORD_LEN.W)), regfile(rs1_addr), 0.U(WORD_LEN.W))
val rs2_data = Mux((rs2_addr =/= 0.U(WORD_LEN.W)), regfile(rs2_addr), 0.U(WORD_LEN.W))
```

最後に、デバッグ用に ```printf``` で出力します。

```scala
printf(p"pc_reg   : 0x${Hexadecimal(pc_reg)}\n")
printf(p"inst     : 0x${Hexadecimal(inst)}\n")
printf(p"rs1_addr :   $rs1_addr\n")
printf(p"rs2_addr :   $rs2_addr\n")
printf(p"wb_addr  :   $wb_addr\n")
printf(p"rs1_data : 0x${Hexadecimal(rs1_data)}\n")
printf(p"rs2_data : 0x${Hexadecimal(rs2_data)}\n")
printf("----------\n")
```
