# デコーダの強化 (Chisel 編)
前回までに、簡単な演算処理を実行可能な RISC-V CPU を実装しました。
ただ、ALU では同じ演算が繰り返し記述され、冗長になっていました。
今回は、類似の演算を共通化するための改良を行います。

## ALU 用デコード
前回実装した ALU では、似たような演算において記述が冗長になっていました。
そこで、類似した演算起動氏は共通化するように実装を変更します。

### デコーダの強化 @ ID ステージ
まずは ID ステージで命令ごとに演算内容とオペランドの種類と解読するように修正します。
具体的には、```ListLookup``` オブジェクトを用いて、演算内容を ```exe_fun```、第1、第2オペランドを ```op1_sel```, ```op2_sel``` に格納します。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val csignals = ListLookup(
    inst,
    List(ALU_X, OP1_RS1, OP2_RS2),
    Array(
        LW   -> List(ALU_ADD, OP1_RS1, OP2_IMI),
        SW   -> List(ALU_ADD, OP1_RS1, OP2_IMS),
        ADD  -> List(ALU_ADD, OP1_RS1, OP2_RS2),
        ADDI -> List(ALU_ADD, OP1_RS1, OP2_IMI),
        SUB  -> List(ALU_SUB, OP1_RS1, OP2_RS2),
        AND  -> List(ALU_AND, OP1_RS1, OP2_RS2),
        OR   -> List(ALU_OR,  OP1_RS1, OP2_RS2),
        XOR  -> List(ALU_XOR, OP1_RS1, OP2_RS2),
        ANDI -> List(ALU_AND, OP1_RS1, OP2_IMI),
        ORI  -> List(ALU_OR,  OP1_RS1, OP2_IMI),
        XORI -> List(ALU_XOR, OP1_RS1, OP2_IMI),
    )
)
val exe_fun :: op1_sel :: op2_sel :: Nil = csignals
```

上記のコードでは、```inst``` がある命令のビットパターンに一致した場合に、命令の種類とオペランドの組み合わせを ```List``` オブジェクトに詰めて ```csignals``` に格納しています。
その後、```csignals``` を展開して、演算命令を示す ```exe_fun```、第1オペランドを示す ```op1_sel```、第2オペランドを示す ```op2_sel``` に格納しています。

次に、オペランドの種類に対応する入力を、```MuxCase``` オブジェクトを用いて、```op1_data```, ```op2_data``` に格納します。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val op1_data = MuxCase(0.U(WORD_LEN.W), Seq(
    (op1_sel == OP1_RS1) -> rs1_data
))

val op2_data = MuxCase(0.U(WORD_LEN.W), Seq(
    (op2_sel == OP2_RS2) -> rs2_data,
    (op2_sel == OP2_IMI) -> imm_i_sext,
    (op2_sel == OP2_IMS) -> imm_s_sext,
)) 
```

### デコード信号を活用した ALU 簡略化 @ EX ステージ
上記で取得した ```exe_fun``` を用いて、EX ステージの記述を簡略化できます。
例えば、```ADD``` と ```ADDI``` や ```AND``` と ```ANDI``` のように、演算対象の組み合わせが複数ある命令を、1行で記述できるようになります。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val alu_out = MuxCase(0.U(WORD_LEN.W), Seq(
    (exe_fun == ALU_ADD) -> (op1_data + op2_data),
    (exe_fun == ALU_SUB) -> (op1_data - op2_data),
    (exe_fun == ALU_AND) -> (op1_data & op2_data),
    (exe_fun == ALU_OR)  -> (op1_data | op2_data),
    (exe_fun == ALU_XOR) -> (op1_data ^ op2_data),
)) 
```

## MEM 用のデコード
これまで、MEM ステージでは書き込み可否信号 ```wen``` の判定のため、命令信号 ```inst``` の解析を行っていました。
ただ、ID ステージであらかじめ書き込み可否をデコードしておくことで、MEM ステージにおける解析処理を省略します。

### デコーダの強化 @ ID ステージ
先ほど追加した ```csignals``` に MEM 用のデコードを追加し、書き込み可否信号 ```mem_wen``` に展開します。
```MEM_X``` は書き込みなし、```MEM_S``` は書き込みありを表します。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val csignals = ListLookup(
    inst,
    List(ALU_X, OP1_RS1, OP2_RS2, MEM_X),
    Array(
        LW   -> List(ALU_ADD, OP1_RS1, OP2_IMI, MEM_X),
        SW   -> List(ALU_ADD, OP1_RS1, OP2_IMS, MEM_S),
        ADD  -> List(ALU_ADD, OP1_RS1, OP2_RS2, MEM_X),
        ADDI -> List(ALU_ADD, OP1_RS1, OP2_IMI, MEM_X),
        SUB  -> List(ALU_SUB, OP1_RS1, OP2_RS2, MEM_X),
        AND  -> List(ALU_AND, OP1_RS1, OP2_RS2, MEM_X),
        OR   -> List(ALU_OR,  OP1_RS1, OP2_RS2, MEM_X),
        XOR  -> List(ALU_XOR, OP1_RS1, OP2_RS2, MEM_X),
        ANDI -> List(ALU_AND, OP1_RS1, OP2_IMI, MEM_X),
        ORI  -> List(ALU_OR,  OP1_RS1, OP2_IMI, MEM_X),
        XORI -> List(ALU_XOR, OP1_RS1, OP2_IMI, MEM_X),
    )
)
val exe_fun :: op1_sel :: op2_sel :: mem_wen :: Nil = csignals
```

### 命令デコードの不要化 @ MEM ステージ
上記の ```mem_wen``` 信号を用いることで、MEM ステージで命令デコードをしなくてもよくなります。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
io.dmem.wen := mem_wen
```

## WB 用デコード
最後に、WB ステージでも同様にレジスタ書き込み可否をデコードすることで、WB ステージにおける命令デコード処理を省略します。

### デコーダの強化 @ ID ステージ
ID ステージでは、さらに追加でライトバック有効信号とライトバックデータの識別信号の解読を行い、```rf_wen``` と ```wb_sel``` に格納します。
```REN_X``` はレジスタ書き込み無効、```REN_S``` はレジスタ書き込み有効を表します。
また、```WB_X``` はライトバックデータなし、```WB_MEM``` はメモリから読み込んだデータを書き込む、```WB_ALU``` はALUの演算結果を書き込むことを表しています。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val csignals = ListLookup(
    inst,
    List(ALU_X, OP1_RS1, OP2_RS2, MEM_X, REN_X, WB_X),
    Array(
        LW   -> List(ALU_ADD, OP1_RS1, OP2_IMI, MEM_X, REN_S, WB_MEM),
        SW   -> List(ALU_ADD, OP1_RS1, OP2_IMS, MEM_S, REN_X, WB_X  ),
        ADD  -> List(ALU_ADD, OP1_RS1, OP2_RS2, MEM_X, REN_S, WB_ALU),
        ADDI -> List(ALU_ADD, OP1_RS1, OP2_IMI, MEM_X, REN_S, WB_ALU),
        SUB  -> List(ALU_SUB, OP1_RS1, OP2_RS2, MEM_X, REN_S, WB_ALU),
        AND  -> List(ALU_AND, OP1_RS1, OP2_RS2, MEM_X, REN_S, WB_ALU),
        OR   -> List(ALU_OR,  OP1_RS1, OP2_RS2, MEM_X, REN_S, WB_ALU),
        XOR  -> List(ALU_XOR, OP1_RS1, OP2_RS2, MEM_X, REN_S, WB_ALU),
        ANDI -> List(ALU_AND, OP1_RS1, OP2_IMI, MEM_X, REN_S, WB_ALU),
        ORI  -> List(ALU_OR,  OP1_RS1, OP2_IMI, MEM_X, REN_S, WB_ALU),
        XORI -> List(ALU_XOR, OP1_RS1, OP2_IMI, MEM_X, REN_S, WB_ALU),
    )
)
val exe_fun :: op1_sel :: op2_sel :: mem_wen ::rf_wen :: wb_sel :: Nil = csignals
```

### 命令デコードの不要化 @ WB ステージ
以下のように WB ステージの命令デコードを省略できます。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val wb_data = MuxCase(alu_out, Seq(
    (wb_sel === WB_MEM) -> io.dmem.rdata
))

when(rf_wen === REN_S) {
    regfile(wb_addr) := wb_data
}
```
