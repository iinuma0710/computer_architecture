# 加減算・論理演算命令の実装 (Chisel 編)
ここからは、加減算命令などの命令を実装していきます。
LW 命令や SW 命令とは異なり、メモリへのアクセスは不要であるため、基本的には ```Core.scala``` を手直ししていくことになります。
また、動作確認は一通り実装が完了したのち、riscv-tests を用いて行います。

## RISC-V の加減算・論理演算命令の定義
RISC-V には、ADD、ADDI、SUB の3種類の加減算命令が定義されています。
それぞれのアセンブリ表現は以下の通りです。

```assembly
add  rd, rs1, rs2
addi rd, rs1, imm_i
sub  rd, rs1, rs2
and  rd, rs1, rs2
or   rd, rs1, rs2
xor  rd, rs1, rs2
andi rd, rs1, imm_i
ori  rd, rs1, imm_i
xori rd, rs1, imm_i
```

また、これらの演算内容は次のように表現できます。

- ADD:  x[rd] = x[rs1] + x[rs2]
- ADDI: x[rd] = x[rs1] + sext(imm_i)
- SUB:  x[rd] = x[rs1] - x[rs2]
- AND:  x[rd] = x[rs1] & x[rs2]
- OR:   x[rd] = x[rs1] | x[rs2]
- XOR:  x[rd] = x[rs1] ^ x[rs2]
- ANDI: x[rd] = x[rs1] & sext(imm_i)
- ORI:  x[rd] = x[rs1] | sext(imm_i)
- XORI: x[rd] = x[rs1] ^ sext(imm_i)

ADD, SUB, AND, OR, XOR 命令は R 形式で、ビットアサインは以下の通りです。

|  | 31-25 | 24-20 | 19-15 | 14-12 | 11-7 | 6-0 |
| :--: | :--: | :--: | :--: | :--: | :--: | :--: |
| ADD | 0000000 | rs2 | rs1 | 000 | rd | 0110011 |
| SUB | 0100000 | rs2 | rs1 | 000 | rd | 0110011 |
| AND | 0000000 | rs2 | rs1 | 111 | rd | 0110011 |
| OR  | 0000000 | rs2 | rs1 | 110 | rd | 0110011 |
| XOR | 0000000 | rs2 | rs1 | 100 | rd | 0110011 |

一方、ADDI, ANDI, ORI, XORI 命令は I 形式で、ビットアサインは以下の通りです。

|  | 31-20 | 19-15 | 14-12 | 11-7 | 6-0 |
| :--: | :--: | :--: | :--: | :--: | :--: |
| ADDI | imm_i[11:0] | rs1 | 000 | rd | 0010011 |
| ANDI | imm_i[11:0] | rs1 | 111 | rd | 0010011 |
| ORI  | imm_i[11:0] | rs1 | 110 | rd | 0010011 |
| XORI | imm_i[11:0] | rs1 | 100 | rd | 0010011 |

## 演算結果の接続 @ EX ステージ
```alt_out``` に演算結果を出力するようにします。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val alu_out = MuxCase(0.U(WORD_LEN.W), Seq(
    (inst === LW || inst === ADDI) -> (rs1_data + imm_i_sext),  // LW, ADDI
    (inst === SW)                  -> (rs1_data + imm_s_sext),  // SW
    (inst === ADD)                 -> (rs1_data + rs2_data),    // ADD
    (inst === SUB)                 -> (rs1_data - rs2_data)     // SUB
    (inst === AND)                 -> (rs1_data & rs2_data)     // AND
    (inst === OR)                  -> (rs1_data | rs2_data)     // OR
    (inst === XOR)                 -> (rs1_data ^ rs2_data)     // XOR
    (inst === ANDI)                -> (rs1_data & imm_i_sext)   // ANDI
    (inst === ORI)                 -> (rs1_data | imm_i_sext)   // ORI
    (inst === XORI)                -> (rs1_data ^ imm_i_sext)   // XORI
))
```

## 演算結果のレジスタライトバック @ WB ステージ
LW 命令ではメモリから読み込んだデータを ```wb_data``` 信号に格納して、レジスタに書き戻していました。
今回の実装では、演算結果もレジスタに書き戻す必要があるため、```MuxCase``` クラスで場合分けをして ```wb_data``` に接続するデータを切り替えます。
次に示すように、デフォルトでは出現頻度の高い ```alu_out``` を渡すようにして、LW 命令の時はメモリから読み込んだ ```io.dmem.rdata``` を渡すように変更します。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
val wb_data = MuxCase(alu_out, Seq(
    (inst === LW) -> io.dmem.rdata
))
```

最後に、LW 命令以外にも ```wb_data``` を ```regfile``` の指定アドレスに書き戻すように変更します。

```riscv/chisel/chisel-template/src/main/scala/Core.scala```
```scala
when(
    inst === LW || inst === ADD || inst === ADDI || inst === SUB ||
    inst === AND || inst === OR || inst === XOR || inst === ANDI ||
    inst === ORI || inst ===XORI
) {
    regfile(wb_addr) := wb_data
}
```
