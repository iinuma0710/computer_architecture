# RISC-V の実装について
FPGA を使ってみたいというのと、低レイヤの勉強をしたいというので、RISC-V CPU を FPGA 上に実装したいと考えています。
それにあたり、RISC-V の概要と実装の方針について簡単に書き留めておきます。

## RISC-V とは
RISC-V とは カリフォルニア大学バークレー校で開発されたオープンソースな命令セットアーキテクチャ (ISA: Instruction Set Architecture) です。
次のような目標を掲げて設計が進められています。

(RISC-V 原典より)
- 組み込みコントローラからハイパフォーマンス・コンピュータに至るまで、すべてのアプリケーションに向けたプロセッサに対応可能
- 普及しているあらゆるソフトウェアスタック、プログラミング言語で動作可能
- FPGA や ASIC、フルカスタムチップなどあらゆる実装形態に対応可能
- あらゆるマイクロアーキテクチャ方式において効率的であること
- 広範な拡張性のサポート
- 安定的であり過去の ISA を打ち切らないこと

また、RISC-V は以下に示す 7 つの尺度によって特徴づけられます。

1. コスト  
   RISC-V を用いることでプロセッサのサイズを小さくし、チップの製造にかかるコストを低減できる
2. 単純性  
   RISC-V は単純な ISA なので、設計や検査、ドキュメント作成にかかる時間を短縮でき、ユーザの理解も容易になる
3. 性能  
   RISC-V はクロックサイクルが速いか、1 命令あたりのクロックサイクル数 (CPI) が少ないため、実行命令数の多さを十分に補える
4. 実装とアーキテクチャの分離  
   別の実装や将来の実装にとって妨げとなり得る、特定のハードウェアに依存した命令を排除している
5. 成長の余地  
   特定のドメイン向けの命令を追加する余地を残すことで拡張性を確保している
6. プログラムのサイズ  
   RV32C 拡張機能を備えた RISC-V は、8 ビット可変長命令の x86-32 よりプログラムサイズが小さくなる
7. プログラミング・コンパイリング・リンキングの容易性  
   RISC-V は 32 個の整数レジスタを備え、コンパイラによるレジスタの割り当てが容易となり、また、1 命令が 1 クロックサイクルで終了するためプログラムの性能を予測しやすくなる

RISC-V は、その名の通り RISC (Reduced Instruction Set Computer) 方式を採用しています。
RISC に分類されるその他の ISA には ARM や MIPS などが挙げられます。
一方、RISC の対義語は CISC (Complex Instruction Set Computer) で、代表的な ISA として x86 や x64 が挙げられます。
CISC と RISC の比較を以下に示します。

| | CISC | RISC |
| :--: | :--: | :--: |
| 回路規模 | 大きい | 小さい |
| 命令長 | 長い | 短い |
| 命令数 | 多い | 少ない |
| 処理時間 | 長い | 短い |
| 学習コスト | 大きい | 小さい |

とはいえ、CISC プロセッサでも内部的には RISC の技術が取り入れられる一方、多くの RISC 方式 ISA では命令の追加が進み、CISC と RISC の技術的差異は小さくなっているようです。

## モジュラー ISA としての RISC-V
多くの ISA では後方バイナリ互換性を維持するため、新しく追加された ISA に加えて、過去の ISA についてもすべて実装する必要がありました。
このような設計手法をインクリメンタル ISA 方式と呼びます。
一方、RISC-V ではモジュラー ISA 方式を採用しています。
この方式では、基本命令セットを中核として、アプリケーションに合わせて拡張命令セットを任意に組み合わせて実装します。
RISC-V には以下のような命令セットが用意されています。(ここに示しているものがすべてではありません。)

| 名称 | 基本/拡張 | 機能 |
| :--: | :--: | :-- |
| RV32I | 基本 | 32ビット整数命令 (レジスタ数32) |
| RV32E | 基本 | 32ビット整数命令 (レジスタ数16) |
| RV64I | 基本 | 64ビット整数命令 (レジスタ数32) |
| RV128I | 基本 | 128ビット整数命令 (レジスタ数32) |
| M | 拡張 | 整数の乗除算命令 |
| A | 拡張 | アトミック命令 |
| F | 拡張 | 単精度浮動小数点 |
| D | 拡張 | 倍精度浮動小数点 |
| Q | 拡張 | 4倍精度浮動小数点 |
| C | 拡張 | 16ビット圧縮命令 |
| V | 拡張 | ベクトル演算 |

RV32I や RV64I の仕様は凍結されており、今後変更されることはありません。
また、RV32I (32ビット整数命令) に加えて、RV32M (乗除算)、RV32F (単精度浮動小数点)、RV32F (単精度浮動小数点)、RV32D (倍精度浮動小数点)、RV32A (アトミック命令) を組み合わせた ISA を RV32G (G は General の意) と呼ぶこともあるようです。
